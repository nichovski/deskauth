# Deskauth - desktop TOTP authenticator

**Date:** 2026-11-03 · **PR:** https://github.com/nichovski/deskauth/pull/1 · **Author:** Bogdan

## What it does

A desktop app (Linux, Windows, macOS) that shows TOTP codes, so 2FA codes can be read without the phone.

- First run: set a master password. Every start after that asks for it.
- Import accounts from Google Authenticator: on the phone, Transfer accounts > Export, then scan the QR with the laptop camera (or load an image). Exports split over several QR codes are collected until all batches are in, then merged once.
- Re-import any time. Accounts with a secret already in the vault are skipped.
- Add one account from an `otpauth://` QR or by typing the secret.
- List with search, Enter copies the top match, click copies a row. The clipboard is cleared after 30 seconds if it still holds that code.
- Auto-lock after 5 minutes of no input.
- Rename, delete, change password, and "Delete vault and start over" when the file is damaged.
- On Omarchy the colors follow the current theme and change live.

## Why

Taking out the phone for every 2FA prompt was the annoyance. Key decisions:

- **No live sync with the phone.** Google Authenticator has no API and its cloud backup is private. The export QR is the only way out, so "sync" means import plus re-import that merges.
- **Camera is the main import path.** Android blocks screenshots of the export screen, so an image import alone would not work for Android users.
- **Each computer imports on its own.** Nothing leaves the machine. No network code at all.
- **Tauri 2.** Small native apps on all three OSes, and secrets stay in Rust; the webview only ever gets labels, codes and counts.
- **Public repo, unsigned builds.** Built for personal use. Others build and sign it themselves (README explains how).
- **No password recovery.** Forgetting the password means deleting the vault and importing again; the phone stays the backup.

## How it works

Rust modules in `src-tauri/src/`, each with in-file tests, and only `commands.rs` and `lib.rs` know about Tauri:

- `account.rs` - account model. The secret is redacted in `Debug` and zeroized on drop; `validate()` guards digits (6/8), period and base32.
- `totp.rs` - RFC 6238 (SHA1/256/512), tested against the RFC vectors.
- `migration.rs` - decodes `otpauth-migration://` (Google's protobuf, structs written by hand with prost derive, no protoc) and `otpauth://`. HOTP and MD5 entries are skipped and counted. Handles a raw `+` turned into a space and `Issuer:name` prefixes.
- `import.rs` - import session: tracks batch id/index/size, ignores repeats, dedupes identical QR content.
- `merge.rs` - duplicate means equal secret bytes, even with a different name.
- `vault.rs` - `vault.json` in the app data dir. Argon2id (64 MiB, t=3, p=1) and XChaCha20-Poly1305, header as AAD, fresh nonce per save, temp file at 0600 then rename. Non-default KDF params are rejected before the KDF runs, so a hostile file cannot force huge memory use. Wrong password and damaged file are separate errors.
- `qr.rs`, `camera.rs` - QR decoding with rqrr; camera via nokhwa on its own thread, frames downscaled to 1280 px before decoding, a small JPEG preview for aiming.
- `theme.rs` - reads `~/.local/state/omarchy/current/theme/colors.toml` and watches `current/` (Omarchy swaps the `theme` directory there on switch), debounced 200 ms.
- `commands.rs` - app state and commands. No code path takes one mutex while holding another. Auto-lock checks both a monotonic clock and the wall clock, so time asleep counts.

UI in `src/` is plain TypeScript, no framework. Rows are keyed by account id and updated in place each second, so clicks are not lost to the redraw. All user and QR text goes in through `textContent`.
